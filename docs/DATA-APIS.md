## 6. 보조지표를 "계산 없이" 받아오는 API

직접 계산이 어렵지 않다면 자체 구현이 낫지만(이 프로젝트는 자체 구현),
빠르게 붙일 때 쓸 수 있는 곳들:

| 제공자 | 지원 지표 | 메모 |
|---|---|---|
| **Alpha Vantage** `function=RSI\|MACD\|BBANDS\|ADX\|OBV...` | 50종 이상 | 무료 키, 분당 5회 제한 |
| **Twelve Data** `/rsi`, `/macd`, `/bbands` | 100종 이상 | 무료 800 req/day |
| **Taapi.io** | 200종 이상, 지표 전용 서비스 | 무료 티어에 지표 1종 제한 |
| **FMP** `technical_indicator/{interval}` | 주요 지표 | 시세와 같은 키로 사용 |

### 직접 계산할 때 쓰는 라이브러리

- JS/TS — `technicalindicators`, `tulind`, `@debut/indicators`
- Python — `TA-Lib`(C 바인딩, 가장 정확), `pandas-ta`, `polars` + 직접 구현
- 이 프로젝트는 의존성 없이 [`src/lib/indicators.ts`](../src/lib/indicators.ts) 에 SMA·EMA·RSI·MACD·볼린저·스토캐스틱·ATR·OBV를 구현해 두었다.

## 알아두면 좋은 보조지표

| 분류 | 지표 | 무엇을 보나 | 흔한 해석 |
|---|---|---|---|
| 추세 | **이동평균 SMA/EMA** | 평균 가격의 방향 | 정배열/역배열, 골든크로스·데드크로스 |
| 추세 | **MACD(12,26,9)** | 단기·장기 EMA 격차 | 히스토그램 0선 돌파 = 추세 전환 신호 |
| 추세 | **ADX / DMI** | 추세의 *세기* (방향 아님) | 25 이상이면 추세장, 이하면 횡보장 |
| 추세 | **일목균형표** | 구름대 지지/저항 | 국내 HTS에서 특히 많이 쓰임 |
| 모멘텀 | **RSI(14)** | 상승/하락 강도 | 70↑ 과매수, 30↓ 과매도, 다이버전스 |
| 모멘텀 | **스토캐스틱 %K/%D** | 최근 고저 범위 내 종가 위치 | 80/20 기준, 단기 매매용 |
| 모멘텀 | **CCI, Williams %R** | 평균 대비 이탈 정도 | RSI 보조 |
| 변동성 | **볼린저밴드(20,2σ)** | 변동성 범위 | 밴드 수축 = 스퀴즈, 확장 = 추세 개시 |
| 변동성 | **ATR(14)** | 하루 평균 진폭 | 손절·포지션 사이징 기준 |
| 거래량 | **OBV / MFI** | 거래량으로 본 수급 | 가격과 방향이 어긋나면 경고 |
| 거래량 | **VWAP** | 거래량 가중 평균가 | 기관 체결 기준선, 데이트레이딩 |
| 가격구조 | **피보나치 되돌림** | 되돌림 목표 | 0.382 / 0.5 / 0.618 |

> 지표는 **가격의 후행 함수**다. 여러 개를 겹쳐 놓으면 같은 정보를 반복해서 볼 뿐이므로
> 추세 1 + 모멘텀 1 + 변동성/거래량 1 정도로 조합하는 편이 실용적이다.

## MVP에 붙이는 순서 (추천)

1. **시세** — Yahoo(또는 KIS) + Binance ← 지금 단계
2. **지표** — 클라이언트에서 자체 계산 (외부 지표 API는 호출 수만 늘린다)
3. **뉴스** — 종목 상세 하단에 네이버/Finnhub 뉴스 5건
4. **매크로** — FRED 금리·VIX 한두 개를 홈 요약에 배치
5. **캘린더·알림** — 실적/지표 발표일 푸시
6. **펀더멘털** — DART/EDGAR는 파싱 비용이 크므로 마지막
